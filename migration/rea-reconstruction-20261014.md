## 本地实现与选择

沿用 Nuxt 4、Vue 3、TypeScript、SSR、项目 CSS 和现有组件。保留进入任务时已有的未提交修改，包括型号页、下载及固件相关工作。

- 首页实现全幅手动轮播、五类产品入口、产品介绍卡片、服务资料与联系入口。
- 页头实现语言菜单、窄屏导航展开、路由切换后收起，以及 Escape 收起。英文菜单使用已观察路径。
- 新天线入口与页面连接到现有产品组件；服务页的电调、图传、天线链接支持本地语言路径。
- 首页与公共页面采用白底、灰色内容区和深灰页头；当前字体回退、卡片排版、移动端断点及横向产品条属于实现选择，不是原站精确测量结果。
- 首页“加入我们”暂接 `#whyus` 服务区；其业务语义和目标站行为尚未确认。轮播只提供手动切换，未加入未经观察的自动播放。
- 使用工作区原有本地图片，不下载或复制新的目标站标识/专有图片。既有素材的版权与授权来源未在本任务中核实；生产发布前需使用已授权素材或原创替代资源。
- 联系页显示待确认的信息，不编造电话、邮箱或地址，也不把图片未读出的内容说成目标站不存在。
- 原有下载中心、固件编译和 WordPress 内容接口继续保留；它们属于本地项目能力，不能据此声称目标站具备同样的 API 或功能。

## 验证与差异

本地只读 SSR 检查通过：41 个静态页面、9 个本地图片资源、35 个链接集合，未发现状态或资源失败。动态任务页需要实际任务 ID；独立 Betaflight 应用另有运行条件，未纳入本轮交互验证。检查脚本为 `/tmp/cshk-local-smoke-20261014.mjs`，只请求本地 GET/HEAD，不提交任务。

`/api/content/products`、`/api/content/downloads`、`/api/firmware/catalog` 返回 200；三者当前均为 `demo-fallback`，不是已验证的正式内容服务。`nuxt typecheck`、生产构建及 `git diff --check` 已通过；最后补充导航与联系文案后重新运行检查。

尚不能完成同视口截图比较：目标桌面场景请求 1440×900，但部分 PNG 为 2160×1350，附加 CDP 场景不能保证启动期全部环境参数；本地浏览器场景也未成功。当前只确认 SSR 与构建，不能声称轮播、菜单、语言点击和移动布局已在浏览器验证。

明显差异包括：本地产品卡片/资料页为组件式重排，页脚保留原项目扩展内容；联系图与精确字体渲染未复刻；天线、下载中心、英文产品详情等有本地新增路径；下载附件与固件任务真实执行未验证。

下一步需要恢复 Edge CDP 可访问性，先枚举匹配目标页并核实证书错误状态，再补采移动端及未观察的公开路由；随后在相同 CSS 视口与设备缩放下验证本地菜单、语言、轮播、资料展开和导航，并比较截图。未执行的点击、下载、API 调用及页面状态不得作为已验证结果。
